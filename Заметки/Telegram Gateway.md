# Telegram Gateway

**Статус:** ✅ Активен  
**Дата подключения:** 17 июля 2026  
**Токен:** Настроен  

## Логи настройки

1. Токен получен от BotFather
2. Gateway запущен в foreground режиме
3. Telegram подключён в polling mode
4. 60 команд зарегистрировано
5. `ALLOW_ALL_USERS=true`

## Команды

- Пишу боту → получаю ответ от Валентина
- `/commands` — список всех команд

## Заметки

- Gateway работает через `HERMES_GATEWAY_NO_SUPERVISE=1`
- Логи: `/opt/data/logs/gateway.log`
- Конфиг: `/opt/data/config.yaml`
- .env: `/opt/data/.env`
